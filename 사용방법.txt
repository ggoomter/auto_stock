================================
  금융 분석 플랫폼 - 사용 가이드
================================

📌 빠른 시작
-----------

1. 앱시작.bat 더블클릭
   → 자동으로 백엔드 + 프론트엔드 실행
   → 브라우저 자동 실행

2. 브라우저에서 작업
   → http://localhost:5173

3. 종료: 앱종료.bat 더블클릭


🗂️ 파일 설명
-----------

✅ 메인 실행 파일
- 앱시작.bat         : 전체 앱 실행 (추천!)
- 앱종료.bat         : 전체 앱 종료
- 파일정리.bat       : 불필요한 테스트 파일 삭제

✅ 개발용 (개별 실행)
- 백엔드실행.bat     : 백엔드 서버만 실행
- 프론트엔드실행.bat : 프론트엔드만 실행

✅ 영문 파일 (삭제 예정)
- START.bat          : 앱시작.bat과 동일
- STOP.bat           : 앱종료.bat과 동일
- run_backend.bat    : 백엔드실행.bat과 동일
- run_frontend.bat   : 프론트엔드실행.bat과 동일


📍 주소 정보
-----------

프론트엔드: http://localhost:5173
백엔드 API: http://localhost:8000
API 문서:   http://localhost:8000/docs


🔧 문제 해결
-----------

❌ "가상환경 생성 실패"
→ Python이 설치되어 있는지 확인
→ Python 3.10 이상 필요

❌ "npm 설치 실패"
→ Node.js가 설치되어 있는지 확인
→ https://nodejs.org 에서 다운로드

❌ 서버가 시작되지 않음
→ 1. 앱종료.bat 실행
→ 2. 앱시작.bat 다시 실행

❌ 포트 충돌 (8000/5173 이미 사용 중)
→ 앱종료.bat으로 기존 프로세스 종료


📁 로그 파일
-----------

- backend\backend_log.txt     : 백엔드 로그
- frontend\frontend_log.txt   : 프론트엔드 로그

오류 발생 시 이 파일들을 확인하세요.


🧹 프로젝트 정리
-----------

1. 파일정리.bat 실행
   → 35개의 테스트/임시 파일 삭제
   → 영문 BAT 파일들 제거
   → tests/ 폴더는 유지됨

2. 정리 후 남는 파일:
   - 앱시작.bat
   - 앱종료.bat
   - 백엔드실행.bat
   - 프론트엔드실행.bat
   - 파일정리.bat
   - tests/ (공식 테스트 코드)


💡 추천 사용 흐름
--------------

[첫 실행]
1. 파일정리.bat 실행 (선택사항)
2. 앱시작.bat 실행
3. 브라우저에서 http://localhost:5173 접속

[일반 사용]
1. 앱시작.bat 더블클릭
2. 작업 완료
3. 앱종료.bat 더블클릭

[개발자]
1. 백엔드실행.bat (터미널 1)
2. 프론트엔드실행.bat (터미널 2)
3. 코드 수정 후 자동 리로드 확인
